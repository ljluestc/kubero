# Kubernetes Package for Kubero

This package provides Kubernetes integration for Kubero, including:

1. The Kubero App Controller for managing Kubernetes resources
2. DNS integration with External-DNS
3. Utility functions for Kubernetes resource management

## Implementation Status

This package is currently under development. Some features may not be fully implemented yet.

## Dependencies

This package requires:
- k8s.io/api
- k8s.io/apimachinery
- k8s.io/client-go
- sigs.k8s.io/controller-runtime
